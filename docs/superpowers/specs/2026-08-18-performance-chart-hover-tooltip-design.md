# 收益曲线悬停提示设计

## 目标

在收益曲线内移动鼠标时，自动选中横轴上距离鼠标最近的数据点，并显示：

- 完整日期
- 组合市值
- 累计投入

该交互覆盖总组合、BTC、CRCL、QQQM+VOO 四个页签。

## 交互设计

图表绘制完成后，在 SVG 最上层增加透明交互区域。鼠标进入绘图区并移动时，根据鼠标在 SVG 视口中的横坐标计算最近的数据点索引。

选中数据点后显示：

- 一条贯穿绘图区的竖向辅助线
- 组合市值曲线上的绿色圆点
- 累计投入曲线上的红色圆点
- 图表上方的悬停提示框

提示框显示完整的 `YYYY-MM-DD` 日期，组合市值使用绿色标识，累计投入使用红色标识。提示框默认位于选中点右侧，靠近图表右边界时自动翻转到左侧，确保内容不被裁切。

鼠标离开图表后，辅助线、数据点和提示框全部隐藏。切换页签或重新加载曲线时，旧的悬停状态立即清除，并对新数据重新绑定交互。

## 数据与边界

继续使用现有 `/api/performance` 返回的 `series` 数据，不修改后端接口。每个有效数据点必须同时具有 `date`、`value` 和 `cost`。

当有效数据点少于两个时，保持现有“暂无曲线数据”行为，不显示悬停交互。鼠标位于绘图区左右边界外时不选择数据点；位于绘图区内时，索引始终限制在首尾数据点之间。

## 实现范围

- `web/index.html`：增加提示框节点、悬停辅助图形和指针事件处理。
- `web/static/style.css`：增加提示框、辅助线和数据点样式。
- 前端测试：验证鼠标横坐标到最近数据点索引的计算，以及首尾边界行为。

不引入新的前端框架或第三方图表依赖，不修改收益曲线的现有数据计算和视觉主体。

## 验证标准

- 四个页签均能显示对应日期、组合市值和累计投入。
- 鼠标从图表左侧移动到右侧时，提示内容随最近数据点变化。
- 辅助线和两个圆点与提示内容对应同一个数据点。
- 提示框在左右边界内完整可见。
- 鼠标离开图表后悬停元素隐藏。
- 现有 Python 测试和新增前端计算测试全部通过。
- 实际页面无相关控制台错误，桌面视口下完成悬停交互验证。
